Ласкаво просимо до офіційного репозиторію веб-порталу нашого Майнкрафт сервера! Цей проєкт містить головну сторінку сервера, технічні модулі, інтеграцію з Discord та нашу власну базу знань (Вікі).

## 🛠️ Стек технологій проєкту
Проєкт побудований на сучасних, легких та ефективних інструментах без перевантаження зайвими фреймворками:
* **HTML5 & CSS3** — кастомна адаптивна верстка з фірмовим ігровим стилем, об'ємними RPG-кнопками та темною темою.
* **Docsify v4** — потужний та гнучкий движок для динамічної генерації документації з Markdown-файлів у реальному часі.
* **GitHub Pages** — автоматизований безкоштовний хостинг для швидкої публікації сайту.

### 📂 Структура репозиторію

| Директорія / Файл | Опис компонента |
| :--- | :--- |
| 📁 `images/` | Медіа-ресурси, системні скриншоти, іконки та RPG-елементи інтерфейсу. |
| 📁 `wiki/` | Модуль бази знань: кастомні стилі `wiki-style.css`, конфіг Docsify та `.md` файли хронік. |
| 📄 `index.html` | Головна сторінка проєкту: бліц-новини, живий статус сервера та навігаційна панель. |
| 📄 `chronicle.html` | Інтегрована сторінка для зручного читання багатовікового лору цивілізації. |
| 📄 `style.css` | Основний файл стилів вебпорталу з темною RPG-темою та об'ємними кнопками. |
| 🛠️ `.nojekyll` | Системний файл для відключення Jekyll, що дозволяє GitHub Pages коректно рендерити Docsify. |

## 👑 Про сервер "Super Server"
Наш сервер — це унікальний ігровий світ, де переплітаються глибокий лор про Великих Титанів, таємничі культи та просунуті технічні механіки. Кожен гравець може зануритися в історію Мандрівників та залишити свій власний слід у хроніках нашої цивілізації.
