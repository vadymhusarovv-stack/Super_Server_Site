## 🛠️ Стек технологій проєкту
Проєкт побудований на сучасних, легких та ефективних інструментах без перевантаження зайвими фреймворками:
* **HTML5 & CSS3** — кастомна адаптивна верстка з фірмовим ігровим стилем, об'ємними RPG-кнопками та темною темою.
* **Docsify v4** — потужний та гнучкий движок для динамічної генерації документації з Markdown-файлів у реальному часі.
* **GitHub Pages** — автоматизований безкоштовний хостинг для швидкої публікації сайту.

---

## 📂 Структура репозиторію
* `/images` — медіа-ресурси, скриншоти, іконки та логотипи сервера.
* `/wiki` — файли бази знань (локальні стилі `wiki-style.css`, конфігурація Docsify та лор-сторінки в форматі `.md`).
* `index.html` — головна сторінка проєкту із бліц-новинами, статусом сервера та навігацією.
* `chronicle.html`, `map.html`, `discord.html` — окремі інтеграційні сторінки для зручності гравців.
* `.nojekyll` — системний файл конфігурації, який дозволяє GitHub Pages коректно обробляти системні файли Docsify.
* `style.css` — основні стилі

## 👑 Про сервер "Super Server"
Наш сервер — це унікальний ігровий світ, де переплітаються глибокий лор про Великих Титанів, таємничі культи та просунуті технічні механіки. Кожен гравець може зануритися в історію Мандрівників та залишити свій власний слід у хроніках нашої цивілізації.
