# 🛠️ Керівництво з розробки та внесення змін (Contributing Guide)

Дякуємо за інтерес до розвитку веб-порталу та Вікіпедії Королівства! 

Щоб зберегти цілісність лору, якість коду та єдиний стиль оформлення, будь ласка, дотримуйтесь наступних правил при створенні Pull Request.

---

## 📜 Основні стандарти лору та статей Вікі

1. **Мова та термінологія:**
   * Усі статті та описи зон складаються українською мовою.
   * Дотримуйтесь єдиного ігрового лору (згадки про Великих Титанів, АРГ-механіки, Організацію «Таємниці Світу»).
   
2. **Форматування Markdown:**
   * Використовуйте стандартні заголовки (`#`, `##`, `###`).
   * Для виділення важливих приміток використовуйте емодзі або стандартні блоки списків.

---

## 💻 Порядок внесення змін (Workflow)

1. Створіть **Fork** цього репозиторію.
2. Створіть нову гілку для вашої задачі.
3. Зробіть комміт із зрозумілим описом.
4. Відправте зміни у свій форк та відкрийте Pull Request у гілку **main**
   
## 🐛 Знайшли баг чи помилку?
Якщо ви знайшли технічну помилку на сайті чи друкарську помилку в тексті лору — будь ласка, створіть новий Issue із детальним описом.
